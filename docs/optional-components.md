# 可选组件补丁：只处理已安装且匹配的版本

这两项不是记忆系统的必装组件。没有安装，跳过本页；先按[升级指南](upgrade.md)完成记忆组件升级。补丁不改变模型账户、代理地址、计费、用户人设或记忆。

| 上游组件 | 本次适用版本 | 改动 |
| --- | --- | --- |
| [lhuans/dsh-genui](https://github.com/lhuans/dsh-genui) | 0.3.1，且文件指纹一致 | 完整卡片规范按需加载，下一轮恢复短说明；卡片渲染与按钮接续保留 |
| [ranxianglei/billion-context](https://github.com/ranxianglei/billion-context) | 0.1.208，且文件指纹一致 | 修复 OpenAI 流的非终止空帧过早输出半截标签；保留真正结束时输出和工具调用 |

两个上游均为 MIT，各自版权保留于 third-party 的许可证文件。这里只分发小范围变换规则及新增按需加载模块，不捆绑上游完整安装包。补丁不是上游已发布修复的声明；同版本也可能有不同构建，文件不匹配即停止，不强行覆盖。新版本应先核对上游是否已经修复。

## 1. 只读检查

让 DSH 从当前使用的 profile 定位实际包目录，不猜默认路径。下面变量由用户实际安装位置填写，不能用整个 profile 或 node_modules 目录代替包目录。

```powershell
$packageRoot = Read-Host '输入实际 dsh-genui 包目录的绝对路径'
node scripts/optional-patches.mjs --component genui --root $packageRoot
```

对于消息代理，改用 `--component billion` 和实际 billion-context 包目录。返回 applicable 才适用，patched 表示已经安装本补丁；其他结果先停下。脚本默认不写文件，不启动模型，不联网。

## 2. 用户知情后手动停机，再应用

DSH 先记录当前 profile、包目录、版本、检查结果和下一步到仓库外的本地升级续接记录，通知用户受影响会话与服务。**用户自行结束任务并手动停止软件；Agent 不调用重启/关机接口，不按进程名批量终止。** 没有第二个 Agent 时，停机后的命令由用户在外部 PowerShell 执行。

消息代理可能是多个客户端共用的独立进程，单独关闭 DSH 不一定停止它。请通过上游管理入口手动停止实际使用的代理；确认其他使用者和请求均已结束。不能靠固定端口、旧 PID 或“DSH 关了”来代替确认。

```powershell
$backupRoot = Read-Host '输入新的私有备份目录绝对路径（父目录已存在，位于仓库和包目录外）'
node scripts/optional-patches.mjs --component genui --root $packageRoot --apply --stopped --backup $backupRoot
```

`--stopped` 是用户确认已经手动停机的声明，不是自动检测或停机命令。脚本先核对所有文件，再保存原件与回执，最后应用并回读。无法匹配的版本或本地修改不覆盖，已存在备份目录不覆盖。

## 3. 用户手动启动，再接续核验

用户手动启动 DSH/代理，回到升级对话，让 DSH 读本地接续记录继续：

- GenUI：普通聊天只带短能力说明；请求卡片时能调用 genui_load_guidance，下一轮恢复简短说明。设置关闭时不继续加载完整规范。
- 消息代理：核对实际使用实例的入口脚本、运行身份和启动代码指纹，不只核对版本号。同版本补丁不会自动改变版本号。旧代理仍存活时不要宣称已生效。
- 补丁不会删除旧助手回复中已经保存的残片，也不是删除所有相似字符串的过滤器。

## 回退与后续升级

先重复用户知情、记录接续、手动停机流程，再用同一个私有备份目录执行 `--restore --stopped --backup`。回退只接受本补丁完整指纹和对应原件，不覆盖随后被修改的安装包；随后用户手动启动核验。

上游更新可能覆盖本地补丁。不要将旧补丁重新强加给新版；重新只读检查，版本或指纹不匹配就交由维护者适配。备份与回执含实际安装位置，只留本机，不上传。
