# 升级说明

返回 [README](../README.md)。本页可以直接交给你自己的 DSH 执行，不需要 Codex。

## 从 0.4.0 升级到 0.5.0

只换记忆插件，人设插件和部署配置都不用动：

1. 在 DSH 档案里卸载记忆插件的 0.4.0 提交，按 [安装说明](setup.md) 第 3 步安装 0.5.0 的固定提交；
2. 按下面的「重启约定」重启；
3. 如果当前记忆库是 0.3.0 的旧库，可以在「维护 → 旧记忆迁移」点一次开始，把旧笔记整理成新格式条目（需要整理模型，会产生模型调用；旧文件不改）。

原有的原话、条目和向量索引原样保留，不需要重建。

## 从 0.3.0 升级到 0.4.0 及以上

## 先了解变化

0.3.0 的组合是「Basic Memory + 记忆桥 legacy 入口 + 纯净模式 + 会话设置」。0.4.0 换成了新的记忆插件 [dsh-memory-starter](https://github.com/XRH66/dsh-memory-starter)（原名 dsh-basic-memory-bridge）：

- 不再需要 Basic Memory、它的 MCP 连接和会话设置插件；
- 记忆默认关闭、按对话开启，所以不再需要纯净模式插件；
- 回答前不再自动注入记忆，由模型按需检索；
- 首次配置改在「记忆框架」页面完成，**新记忆库必须是一个新目录**。

旧记忆可以继续用。0.3.0 生成的部署目录里，`data/` 下是 `vault/`（笔记）和 `management/`（状态），新插件能直接把这个文件夹当作记忆库使用：旧笔记按原样读取和检索，不会被改写。下面第 5 步讲怎么切过去，0.5.0 起还可以用第 6 步把旧笔记迁移成新格式。也可以不切，从一个空的新库开始。

## 步骤

1. **记录现状。** 找出当前使用的 DSH 档案、已装插件及版本、旧 Vault 和 Basic Memory 配置的位置。路径从本机现有配置读取，不照抄别人的。
2. **备份。** 把 DSH 档案配置、旧 Vault 和 Basic Memory 的数据目录备份到仓库和 Vault 之外。SQLite 要用在线一致快照，或确认所有写入停止后再复制，不能直接复制正在使用的数据库文件。
3. **换插件。** 在 DSH 档案里卸载旧记忆桥（dsh-basic-memory-bridge 的旧提交）和纯净模式插件，按 [安装说明](setup.md) 第 3 步安装新插件。人设插件 dsh-global-settings 0.2.0 不用换。会话里勾选的 `basic_memory` MCP 不再需要，可以在会话设置里关掉；要不要卸载 Basic Memory 本身由你决定。
4. **重启并完成首次配置。** 按下面的「重启约定」停下，由用户手动重启。在「记忆框架」首次配置页填一个**新的**记忆目录（首次配置只接受新目录，这个库只是过渡用），选整理模型，勾选一个对话，点启用，再重启一次。
5. **切回旧库（想保留旧记忆时）。** 先确认旧记忆桥已经卸载、旧库没有正在跑的整理。在「维护」页的「记忆库」一栏，把旧部署的 `data` 文件夹完整路径（里面直接有 `vault` 和 `management` 两个文件夹）填进「另一个记忆库」，点「选择此记忆库」，再重启一次。重启时会先检查两边有没有待处理内容，有就不切换，页面会显示原因；处理完再重启即可。切换后，第 4 步建的过渡库可以删掉。
6. **迁移旧笔记（0.5.0 起，可选）。** 切到旧库后，在「维护 → 旧记忆迁移」点开始，后台把旧笔记整理成新格式条目，拿不准的进「待确认」由你处理。不迁移的话旧笔记也照样能读取和检索。
7. **重建索引。** 想用向量检索的话，在「记忆」页打开「原话检索」，到「检索模型」页选好模型，再在「状态」页点「准备索引」，让旧笔记进入新索引。不开向量时，旧笔记也能通过全文检索找到。
8. **核对。** 设置页有四个分页；「维护」页显示的当前记忆库是你选的那个；开启记忆的对话下一回合能保存原话；人设和自我档案仍正常加载。

## 重启约定

每次需要重启前，执行者先说明会影响哪些对话和后台任务，把当前步骤、已改文件、备份位置和下一步写进仓库外的 [续接记录](../examples/upgrade-progress.md)，然后停下，等用户自己重启。执行者不调用自动重启、强杀进程或电源类插件。重启后先读续接记录，核对实际加载的插件版本，再继续下一步。

## 出问题时

停在出错的那一步，保存错误信息。回退时把插件换回旧提交、恢复第 2 步备份的配置即可。新插件在旧库里新增的记录（原话库、条目、索引）不会被旧版使用；回退时不要用旧备份整体覆盖这些新产生的数据，先单独保存一份。
