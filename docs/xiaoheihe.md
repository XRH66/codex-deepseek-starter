# 给 DSH 的记忆加一个可关闭的开关：0.3.0 更新介绍

日常聊天希望它能接住前面的话，做任务时又希望暂时放下个人记忆。这次更新把这两种需要放到同一套 DSH 里：新对话第一条消息前就能打开纯净模式，日常聊天则继续使用原有个人库。

纯净模式从下一新回合起关闭全局人设、自我档案注入和个人记忆工具，不改你的 MCP 勾选、AGENTS、模型和权限。它不会抹掉旧聊天里已经说过的话，所以真正从头做任务，仍建议新开空白对话。升级旧桥时，后台任务也要单独隔离，不能只看开关亮了。

记忆部分增加了近期聊天缓存，方便换个对话接着聊。缓存只保存直接用户与最终助手文本，不收集隐藏思考和工具输出；从升级后的新消息开始积累。长期记忆的几路召回现在统一筛选和去重，在共同正文预算里选材料，而不是每轮把所有缓存都发出去。

“以前说过”和“现在要求”也分得更清楚：同一范围按最新明确要求处理，旧说法保留为历史，需要追溯再查。一次性的“这次简单一点”不会因此变成长期规定。遗忘、索引和强化不是这次才有，旧版就已具备；整理时会保留原来的日期、身份、衰减与强化依据，不自动物理删除记忆。

已有的状态面板补上了分环节用量和召回解释。没有回执的历史用量会标未知，不把字符数冒充 token，也不把输入量直接当费用。标准原生工具模式 + High 已在小型隔离环境验证长期召回、自动写入/纠正和跨会话接续；这不能代表你的长对话会同样快，更不能承诺永不漏记。

升级可以把 [升级指南](upgrade.md) 交给你自己的 DSH，不需要 Codex：先确认版本路径、做一致备份、安装并验证基础设施，再按自己的来源整理旧库。凡是需要重启，执行者先写本地续接记录并暂停，由你知情后手动重启，再读记录继续。没有万能迁移清单，也不会把别人的私人记忆当模板塞给你。

项目基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 与 [Basic Memory](https://github.com/basicmachines-co/basic-memory)，使用 [u9521 的会话设置](https://github.com/u9521/dsh-session-settings)，可用 Obsidian 查看同一个库。本项目维护记忆桥、全局设置与 [纯净模式插件](https://github.com/XRH66/dsh-pure-mode)；第三方来源和许可见 [NOTICE](../NOTICE.md)。[可选组件](optional-components.md) 中的 GenUI / billion-context 补丁另行说明，不算作全部自研。

入口：[主仓库](https://github.com/XRH66/codex-deepseek-starter)、[更新记录](changelog.md)、[验证与限制](validation.md)、[隐私说明](privacy.md)。个人库仍是单人方案，本地存储也不等于模型推理离线。
