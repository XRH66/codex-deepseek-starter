# 大肥鱼记忆系统更新：换个对话接着聊，新旧要求不打架

上一版大肥鱼已经实现了自动记事、索引整理、自然遗忘和强化。这一轮主要围绕实际聊天体验打磨：减少重复回忆，让最近的话接得上，让修改过的要求真正生效，也把更多管理工作交给代码自动完成。

**新版代码和升级说明已发布，更新安装与旧库整理分别提供指南。**

> **版本提醒**：本次更新的是记忆插件与配套方案，已验证的 DSH 版本为 **0.2.1-rc.2**。官方 **0.2.2-alpha.2** 涉及插件接口调整，目前尚未完成兼容验证。使用本方案的朋友先不要直接跟着升级宿主。[适配与验证记录](validation.md)

### 1. 换个对话，也能接着刚才聊

上一版只有被正式提炼并存进长期记忆的事，换个对话才能找回来。随口说的一句话，没被保存就可能接不上。

现在增加了**本地近期聊天缓存**。哪怕还没来得及提炼成长期记忆，最近聊过的内容也会暂存在本地，供其他对话接续。缓存按容量滚动，满了淘汰最早的整轮，不会过了零点就清空；每轮只选取片段，不全文灌给模型。从新交流开始积累，不回填全部旧聊天。

目前覆盖接入这套记忆桥的 DSH 对话；微信、QQ 等入口需要另外接入。

### 2. 要求改了就按现在的执行

以前说“回答短一点”，后来改成“长短自己决定”，旧说法可能一直干扰回复。现在将**当前有效要求和历史记录分开保存**：同一件事、同一适用范围内，以最新明确要求为准；工作要求和闲聊偏好可以分别保留。

日常优先读取当前要求，需要追溯变化时再查历史。一次性的“这次只答一句”不应变成永久偏好；来源不明或冲突的旧记录需要审阅。

### 3. 回忆更集中，减少重复内容

同一件事可能从事实、索引和近期动态同时被找出来。现在由代码统一筛选、依据标识和规则去重，并控制记忆正文长度。

检索时参考最近的对话，为“它”“刚才那个”等说法补充线索。上一轮遗留的自动注入会从模型视图清理，避免层层堆积；原始聊天仍保留。

### 4. 减少旧材料干扰，给自然表达留出空间

当前自我档案优先，过去的聊天例句不作为今天必须照着说的模板。这次没有增加长篇人设，也没有规定每句话怎样开头结尾，重点是减少新旧偏好和无关材料的冲突。

### 5. 纯净模式，一键切换

想临时做任务、查资料，不带入养鱼记忆，可以开启当前会话的纯净模式。生效后停止自动召回和写入个人记忆，停止注入全局人设、自我档案和近期聊天，保留 AGENTS 与工作工具。

**开关按会话保存，从下一新回合生效。** 建议新开空白对话并在第一句话前开启；旧聊天不会被清除。此前普通回合已产生的后台整理任务不会自动取消，升级维护仍需单独暂停后台写入。

### 6. 失败会补写，但不会无限重试

失败后按间隔重试，默认连续自动失败三次后暂停，保留任务与处理进度。可以在状态面板查看并手动恢复，不会无限重复尝试同一失败任务。

### 7. 记忆状态面板升级

在“DSH 全局设置”的记忆状态入口，可以查看后台整理耗时与 token 用量、各路召回原因、重复过滤统计，以及近期缓存占用和暂停任务。没有用量回执时显示未知，不把字符数当成供应商账单。

### 8. 修复与细节优化

**记忆桥自身修复**：修正旧自动注入清理时机引起的部分会话恢复与发送异常。

**第三方组件可选补丁**：对应版本的 billion-context 修复已定位的符号流残留；对应版本的 GenUI 将完整卡片说明改为按需加载。没装这两个组件，不影响核心记忆功能。补丁先核对版本和文件指纹，具体见[可选组件](optional-components.md)。

### 9. 更多重复工作交给代码

代码负责保存近期聊天、滚动淘汰、发起检索、规则去重、控制注入长度、保存新旧版本、计算遗忘衰减与失败重试。

模型负责理解语义、判断什么值得记住、归纳主题，以及自然地组织回答。上一版已有的索引、遗忘和强化机制继续使用。

### 存储与配置建议

记忆在本地保存，长期笔记可以通过 Obsidian 查看和修改；近期缓存和运行状态也在本机。使用在线模型时，相关内容会随请求发送给你选择的 API。自然遗忘降低召回优先级，**不会自动物理删除长期记忆**。

日常养鱼建议先用**标准模式 + High**；已通过自动召回、后台写入和跨会话接续的隔离验证，不必为了记忆功能一直开着 PTC 或 Max。

### 怎样升级

旧库不用推倒重来。先按升级指南更新插件、确认运行正常，再按旧库整理指南处理已有记忆和索引。涉及重启，让 DSH 先说明影响、保存进度，等待你手动重启后继续。

发布包不含作者的私人记忆、人设或凭据；升级按差异合并配置，保留你的个人内容。
