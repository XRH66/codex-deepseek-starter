# 隐私与公开边界

返回 [README](../README.md)。

## 仓库里有什么

公开内容只有脚本、技能、说明、虚构示例、必要测试、依赖锁文件和上游许可原文。两个自研插件的源码在各自仓库，这里按固定提交引用。

实际的凭据、DSH 配置、人设、自我档案、聊天、记忆库、数据库、备份和运行状态都在仓库外。配置生成器只接受仓库外还不存在的新目录，不覆盖已有设置，也不启动服务。

`npm run privacy` 把实际文件列表和 `release-files.json` 对比，并检查盘符路径、会话身份、常见密钥格式、运行目录、二进制和压缩包。可以在本机设置环境变量 `RELEASE_FORBIDDEN_TERMS`（逗号分隔）追加用户名、原部署目录等敏感词，不必把它们写进检查代码。扫描只是辅助，识别不了所有自然语言里的隐私，改示例和说明时仍需人工检查。

## 记忆数据

- 记忆默认关闭，只有你开启的对话才会保存原话。原话库、索引和状态在记忆目录的 `management/` 下，整理出的条目在 `vault/` 下。
- 本地存储不等于推理离线。开启记忆的对话、后台整理的内容会发给你选的对话模型和整理模型；选用接口向量模型或重排服务时，被索引或被检索的内容也会发给这些服务。
- 接口密钥单独保存在管理目录，配置里只存引用，设置页不回显。
- 人设作为全局系统提示词；自我档案只在开启记忆的对话里读取。
- 本方案面向单人使用，不提供多人或群聊之间的隐私隔离，也不做跨机器同步。
- 备份和升级续接记录里可能有敏感内容，只留在本机，不要上传。

## 工程控制附录

只有选择工程控制模式时，才会在部署目录生成控制 token（`mcp-token.private`），重启时复用，这个文件不能公开。CLI 只连接本机回环地址，拒绝远端地址和 URL 里内嵌的凭据，并精简传输错误以免回显认证信息。任务正文和结果仍可能包含你主动提供的敏感内容，不要直接贴到公开 issue。默认的记忆模式没有这个 token。
