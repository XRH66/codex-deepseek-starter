# 隐私与公开边界

返回 [README](../README.md)。

公开内容只包括脚本、技能、说明、虚构示例、必要测试、依赖锁文件及原始许可。自研插件源码位于各自独立仓库，主方案通过固定提交引用。

实际凭据、Codex/Harness配置、persona、自我档案、聊天、Vault、数据库、图片、备份、运行状态与任务身份保存在仓库外。配置生成器只接受仓库外尚不存在的新目录；不会覆盖已有设置或启动服务。

运行 `npm run privacy` 会对实际文件列表与 `release-files.json` 比较，并检查固定盘符路径、会话身份、常见密钥、私人运行目录、二进制及压缩包。还可通过仅本机设置的 `RELEASE_FORBIDDEN_TERMS`（逗号分隔）追加用户名或原部署目录等敏感词，不把这些身份信息写进检查代码。新增文件必须审查后显式列入白名单。`.git` 与依赖 `node_modules` 不属于源码上传内容；依赖可保留供本地使用，但提交仅包含白名单文件。

扫描是辅助检查，不能识别所有自然语言隐私；修改示例、测试或说明时仍需人工审查内容。不要把扫描规则的通过当成任意文件均可公开的许可。

MCP控制token可控制目标实例会话；CLI只连接字面值loopback地址，拒绝远端地址与URL内嵌凭据。CLI精简传输错误，避免SDK错误回显认证信息；任务正文与最终结果仍可能包含使用者主动提供的敏感内容，不应直接复制到公开issue。

记忆数据保存在本地，但需要整理或回答时会发送相关内容给当前模型。人设作为全局系统上下文；自我档案属于软上下文；记忆工具的本地删除限制不能替代服务端访问控制。当前方案用于单人环境。

发布前检查当前白名单文件及各插件来源，不上传依赖目录或现用部署的Git历史。部署脚本首次在用户选择的仓库外目录生成控制token，重启时复用；此文件不可公开。主方案不内置发布凭据或自动推送行为；依赖插件的公开仓库单独维护。
