## 0.3.0 配套代码证据与发布验收边界

以下是已核实本地说明的脱敏结论，不分发私人实验目录；它们不等于本次公开发布提交已经在全新机器验收。

| 范围 | 已有证据 | 结论边界 |
| --- | --- | --- |
| 近期聊天 | 真实桥事件与Go模型的隔离跨会话接续；只收集直接用户/最终助手文本，纯净访问限制另有检查 | 最初试验BM仅用拒写工具定义；不能冒充真实写库验收 |
| 当前要求/旧库 | 当前值与历史分离、范围冲突、临时要求、真实BM索引与读回；保留元数据和队列 | 私人一次性清单不可复用；任意语义识别不保证正确 |
| 统一召回与观察 | 去重、正文预算、旧自动块清理；用量按实际回执记录、未知回执不记零 | 字符不是token；单样本比例不能外推节省率或费用 |
| 标准原生工具 + High | 原生ToolRuntime/SessionStore、真实隔离BM与Go模型：长期事实召回、轮后写入/纠正、第三会话接续；持久日志严格恢复、队列清空 | 小型隔离上下文，不是生产UI长聊天性能对比；接续答案另有长期事件召回，不能唯一归因于近期通道 |
| 会话恢复 | 清理移至step/start后的agent/request边界；原生严格恢复、真实历史/状态接口，随后用户已有真实消息与页面可见性核验 | 只覆盖已识别日志形态，不提供批量自动修日志；health ready不等于会话接口就绪 |

原生 High 的成功三轮模型完整回复约1.8–3.5秒，后台整理另计；这些小型隔离样本不能用于承诺原长聊天速度。冷启动种子索引曾出现首次搜索为空，内部根因未确定；正常运行中新写事件可在下一会话召回，不据此保证所有新库首写立即可搜。

本次发布检查不调用模型、不修改正式环境。已从公开远端重新克隆记忆桥、设置和纯净模式，并成功执行锁文件安装；桥的配置与集成8项、设置22项、纯净模式12项检查通过。纯净模式与真实桥的联动另在发布工作副本验证。安装说明固定这三个已发布提交。主仓库另执行临时目录配置/启动mock、CLI本地mock及 links/privacy 检查。未在另一台机器重新执行四插件完整UI部署；用户升级后仍须确认实际加载版本。GenUI/billion-context 的证据与安装边界见 [可选组件](optional-components.md)。


可选补丁发布检查：已在两个真实上游副本完成只读检查、应用、回读、幂等、冲突拒绝与恢复的隔离验证，没有操作生产；此为补丁部署路径验证，不新增模型或用户UI验收。升级时还需检查 profile 的显式 captureTimeoutMs / captureMaxTokens 覆盖项；新版90000ms/8192 token只是后台上限，实际生效值不能只看源码默认。
